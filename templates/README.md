# 3D 模板提炼入口

## 候选类型与参考

现有实例是参考作品，不等于已经抽象完毕的模板。以下类型均待逐例审查和新问题试用。

| 候选类型 | 现有参考 | 首要检查 |
|---|---|---|
| 装配与分层拆解 | [CVD 三维炉体](../examples/cvd-structure-3d.html) | 稳定部件身份、分阶段避让、深度遮挡和重装配 |
| 空间结构与基准比较 | [晶体缺陷](../examples/crystal-layer-labels.html) | 同位置比较、整体连续运动、避免辅助面冒充缺陷 |
| 设备结构与功能联系 | [CVD 设备总览](../examples/cvd-furnace.html) | 结构、流路、作用能否连起来；是否确实需要三维 |
| 二维与三维联动 | [球体截面](../fragments/sphere-section.html) | 相机不改模型，截面有明确教学用途才加入 |

CVD 的基础显示与部分几何、时序已有检查记录；增强 GPU 渲染与实际移动设备多指触摸不能由此视为已全部验证。历史 archive 不作为默认模板来源。

## 模板工作方式

此目录目前是模板提炼的工作入口，不是已验证的通用组件库。先选一个代表例子，完成检查，再抽取可复用部分；没有合适例子或不能讲清的类型暂缓，不凑数量。

1. 复制 [模板工作稿](authoring-brief.md)，填清学习目标、模型条件、视觉含义与动作后果。
2. 复用已有实例中被认可的能力；记录来源路径，不复制整批历史版本。
3. 在一个新的教学问题上试用，检查模板是否仍成立。
4. 记录实际检查证据，区分“实测”“源码审查”“待验证”。通过后再提供独立 HTML 模板及使用说明。

每个最终模板应包含：可运行 HTML、适用与不适用范围、模型接入点、主题接入点、已验证环境及未解决事项。新科学模型仍需单独核实，换主题不能替代模型设计。

## 每例检查表

- [ ] 不读长段说明，能辨认对象、正在变化的部分和变化结果。
- [ ] 比较前后保持尺度、观察位置、对象身份与非干预条件。
- [ ] 输入、固定条件、派生量清楚；相同状态驱动画面、数值和说明。
- [ ] 动画可暂停、反向和中断，途中切换不会留下旧状态。
- [ ] 控件操作有立即可见的后果；无作用的重置和重复选择不占界面。
- [ ] 手机、平板和目标展示环境分别检查；未做的项目保留待验证。
- [ ] 颜色、布局、字号等 UI 项记录到共用 UI 工作，不在每例各做一套。

## 新一轮：拆解与截面

- [薄膜叠层](../fragments/film-stack.html)：同一组三层材料连续拆开与复合；厚度夸张，非真实剥离过程。
- [球体截面](../fragments/sphere-section.html)：球体保留切面以下区域，联动二维正视截面。r/R=sqrt(1-(h/R)^2)，截面不是另一种材料。

片段用于会话预览，需要宿主主题样式；不是独立部署页面。原生WebGL深度缓冲实现遮挡；未引入外部模型。底部整片空白短按恢复该示例全部观察状态，控件操作与拖动排除；R键等价。图上拖动旋转、双指缩放。实际网格已用EGL/GLES检查渲染，模拟DOM执行主要状态与复位；Android多指和完整宿主布局仍待验。约定记录见contracts同名JSON。

## 空间连通：介电层与通孔

[通孔连通](../fragments/via-connection.html)现显示上下嵌入金属线、介电材料和通孔侧壁阻挡/衬层。完整和剖开视图共用几何，剖开隐藏所有z>0材料，不冒充物理刻蚀。有无通孔保留同位置对照；无通孔时该区域为连续介电材料。空白复位只恢复相机，不清除锥度或结构选择。

侧壁倾角0–12°是形状对照，固定底径和介电厚度，上口随角度派生。默认9°仅为可辨认的示意，不能声称通孔普遍如此。直壁、带锥度和分段轮廓均存在，必须按具体工艺建模。通孔侧壁阻挡/衬层合并并夸大显示，省略其他薄层，不代表完整生产集成方案。

验证：12种完整/剖开、有/无、0/9/12°组合生成并渲染；模拟DOM检查输入、对照、复位与拖动。Android多指与宿主整体布局待验。详细来源与简化说明见[研究记录](../docs/via-structure.md)，语义及证据见contracts/via-connection.json。

后续3D按用户要求一次一个，先保留解释关系所必需的环境和界面，避免以简洁为由删去关键材料。

## 框架3.1采用边界

候选类型作为参考索引，不构成硬性清单。允许旋转、爆炸、剖切、切片、隔离、局部放大、场与过程按教学目标组合；一次选最少足够方式。新模型可扩展，记录现有方法的缺口与验证。详见[开放创作规则](../docs/platform-policy.md)。

通用片段打包与主题接口由[2D接入层](https://github.com/Xiatiantian1997/2d-scientific-interactions/blob/main/docs/host-integration.md)提供。隔离同页不等于物理耦合；WebGL旧例材质需独立适配，Android和Notion宿主仍需真实验收。
