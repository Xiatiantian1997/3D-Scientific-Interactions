# 表示与触摸

## 从理解障碍选方法

| 理解障碍 | 优先方法 | 不适用时 |
|---|---|---|
| 不知结构怎么形成 | 连续构造、分解、可回退步骤，保留对象身份 | 实际过程不是该构造时标成数学构造 |
| 遮挡、方向或层间关系 | 按需要选择三维旋转、隔离、透明或剖切；截面联动仅在有独立解释价值时加入 | 读精确数值时保留二维图表 |
| 看不出参数影响 | 改一个自由输入、联动结果、冻结基准 | 多因素实验需按任务开放组合而非永久一次只能改一个 |
| 不懂公式各项 | 对象、量、公式项对应；保持其他项，比较本项效应 | 非线性耦合不能默认逐项相加 |
| 不懂局部量 | 点按/拖动探针，即地读数，必要时显示局部方向或邻域 | 点没有独立语义就删去 |
| 不懂整体如何由局部形成 | 单对象→少量关系→群体或场，支持返回局部 | 粒子仅作表示时别宣称是真实微观轨迹 |
| 不懂算法步骤 | 步进、回退、分支选择、状态与代价同步 | 动画速度和播放秒数不等于复杂度 |
| 不懂尺度关系 | 改采样尺度并显示计数、对数图或参考尺度 | 单纯缩放镜头不能代替重新计算 |

这是选择表，不是每个组件都必须包含的功能清单。

## 手势设计

把每种手势绑定明确的意图：对象拖动改变输入，空白区拖动旋转或平移视角，探针读取局部，进度拖动推进过程。发生冲突时减少模式或提供清晰的模式切换，不要让同一触摸依隐藏状态执行不同操作。

建议优先直接拖对象；多指仅用于有价值的视角/尺度操作，不为展示多指能力添加复杂手势。为触摸开始时的目标提供视觉反馈；可见元素可以小，命中区应足够大，但不能遮住邻近对象或拦截整页滚动。代码实现时验证 pointer capture、pointercancel、移出画布、双指中途抬起、页面滚动和缩放恢复。针对手势拥有的区域设置 touch-action，勿全页禁用浏览器缩放。

重置应说明恢复什么：模型、相机或两者。必要时分开，勿让一次“复位视角”毁掉实验状态。辅助入口需可触达，不能只支持悬停；提供键盘/按钮等价操作和减少动态效果的方案，以适配实际交付环境。

## 动画与视觉层级

用稳定的颜色、轮廓、位置锚点和标注保持身份；颜色不能是唯一识别方式。建立明确的注意重点；任务需要耦合变化时保留联动，次要细节可以逐步出现。转场可以柔和，但不能将不合法模型状态插值成似乎可行的过程。数值积分按仿真时间处理，不依赖屏幕帧率改变物理结果。

保留必要标签；降低辅助控件的视觉重量，不通过把正文变得难读来制造主次。小屏幕优先看到对象、操作和反馈；不要先铺一屏说明、标题或卡片。可用紧邻注释解释当前变化，不把每个小交互做成多页应用。

## 让解释可以检查

在适用的任务中选择一种证据，不要求全部上屏：

- **观察方式切换**：固定位置取样与跟随对象取样使用同一物理状态，标清位置和时间。观察者改变不等于外部输入改变，也不必然是坐标系变换。
- **收支核对**：同时显示边界流入、流出、内部存量变化及生成/消耗。不能把某个不可压缩示例的“流入等于流出”推广到所有传质过程。拖动控制区域改变统计范围，不应制造物质。
- **规则执行轨迹**：把当前状态、触发的规则、下一状态和代价对应起来；允许步进和回退，历史与计算一致。区分找到一个解、检验给定解、证明无解。
- **约束跨表示保持**：从原问题变成另一图形或符号时，可选中同一对象/约束看其对应项；转换须保持所声称的性质，不能只用相似动画暗示等价。
- **误差与适用边界**：需要近似时显示目标、近似和有单位的残差；说明残差检验了什么，不能把有限样本或小残差当作普遍证明。放大示意、时间加速、物理模型失效尺度应可辨认。

视频中的展馆、镜头飞行和密集总览不必搬进小型 HTML。保留稳定的对应关系与按需展开，常可用更简单的二维布局完成。
