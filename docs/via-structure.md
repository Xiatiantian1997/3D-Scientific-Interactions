# 通孔结构：研究与表示

## 修订依据

上一版适合孤立解释投影重叠与连通，却隐藏全部介电层、只给理想圆柱，无法承担后道互连结构讲解。新版恢复周围介电材料，并区分观察裁切、几何形状对照和实际工艺过程。

## 查到什么

1. 介电层是互连环境的一部分，承担导体之间绝缘；现代互连还涉及低k介电、阻挡与衬层。Applied Materials官方介绍：https://www.appliedmaterials.com/us/en/semiconductor/markets-and-inflections/advanced-logic/interconnect.html
2. 带锥度的孔确实存在，也可为上段倾斜、下段近垂直等分段轮廓。所读Siemens/Infineon专利公开记录：https://patents.google.com/patent/EP0871213A2/en ，图2与侧壁描述。专利说明一种技术方案，不能用于推断所有节点的普遍轮廓。
3. 近直壁孔同样存在，旧柱状通孔工艺也讨论了其节约平面面积的动机：https://patents.justia.com/patent/4621045 。这是历史工艺证据，不是现代比例统计。
4. imec两金属层互连示意与制造说明：https://www.imec-int.com/en/articles/imec-demonstrates-semi-damascene-interconnects-fully-self-aligned-vias-18nm-metal-pitch 。没有把TSV或封装激光微孔的轮廓直接套到芯片内BEOL。

## 新版范围

局部两层互连；金属统一颜色、介电材料另一固定颜色、通孔侧壁阻挡/衬层为第三种材料编码。侧壁阻挡与衬层合并为示意薄层并夸大，未分别画其成分与真实厚度，也未画金属线的所有附属薄层。不是完整制造流程或精确节点模型。

孔截面采用圆形，半径从底部rb=.18沿H=1高度线性变到rt=rb+H tan(theta)。theta相对竖直，0°为直壁；0–12°及默认9°只供形状比较，无工艺标定。底部有有限面积接触，因此是圆台近似而非尖圆锥；实际平面形状不保证是圆。

完整/剖开只是可见区域切换。无/有通孔为两个结构设计对照，不解释成原子凭空增减或制造动画。无通孔时该处是介电材料而非空洞。默认剖开整个前半体，材料切口一致，不把辅助面涂成实际物理层。

## 后续创作原则

先确定教学目标所必需的环境、界面与部件，再删细节。仅声明“已隐藏”不保证隐藏合理。真实轮廓查阅特定材料、节点和工艺来源；示意几何与真实工艺分开记录。不要因用户指出锥度就把“所有通孔均圆锥”写进通用规范。
