# 模型约定

在作者工作材料中填写以下短表，不要求用户逐项决定，也不默认展示给学习者。

| 项目 | 需要明确的内容 |
|---|---|
| 学习目标 | 一次操作后能回答的具体问题 |
| 系统 | 对象、边界、参考系、模型适用条件 |
| 可控输入 | 当前实验可直接改变的量、单位、范围 |
| 给定条件 | 此次实验固定的材料性质、结构、环境或设备条件 |
| 状态 | 随时间演化或由约束求解的量 |
| 派生量 | 从状态计算的读数、曲线、统计量 |
| 约束 | 守恒、代数关系、初始/边界条件、合法状态 |
| 观察状态 | 相机、探针、截面位置、图表缩放、播放进度 |
| 求解 | 解析、数值积分、联立、迭代或明确标注的示意 |
| 证据 | 使用的书页、论文或可靠文档；未核实内容 |

## 可操纵性取决于实验

对于固定质量物体，在惯性系和经典力学适用范围内，合外力变化会对应加速度变化。这里 m 固定是系统设定；并非任何物理问题里质量都不能改变。a=dv/dt 是定义的物理量，有明确的运动学含义，不能因其由人定义就说没有物理意义。F=ma 本身不能单独规定所有实验的干预方向；反馈控制下也可能设定加速度再求所需驱动力。变质量系统需从合适的动量平衡建模，不能机械套用固定质量例子。

不要把材料常量一律当绝对常量；有效质量、迁移率、介电性质等可能随模型条件变化。显式标出本模型将什么近似为常数。

## 代数依赖、动力学、因果分开

- 代数约束描述允许同时成立的状态，可由多个变量共同决定。
- 动力学给出状态怎样随时间更新，需要初始条件。
- 因果判断需要物理机制与干预条件，不能从等式书写方向直接得出。
- 自洽模型可能形成循环：将“输入→求解器→一致状态→观察量”作为交互结构，不强行画成无环因果链。
- 禁止把每个公式符号都变成独立滑条。切换控制方式时重新指定自由变量，保持约束成立。

## 三类时间与尺度

区分真实时间、仿真时间和构造步骤。拖动教学构造的进度并不等于物理系统按这个路径演化。区分屏幕放大、采样分辨率和改变对象尺寸；解释指数、维数或尺度律时尤其不能混淆。

## 不确定性与反事实

统计拟合不自动代表物理因果。固定条件比较参数效应；有噪声时提供合理重复或同一随机样本比较，不暗中每次随机重抽。标明示意幅度、归一化、夸张比例及近似模型，避免用漂亮动画掩盖误差。

## 多尺度与化学反应

宏观流线、浓度标记、微观分子和原子分别声明对象及单位，不共享未解释的同一“点”。同种元素在反应前后保持身份；反应改变成键、化学物种、位置与相态，不能因离开气相变成固体就改画为另一元素。示踪粒子不是分子动力学轨迹；快慢不作定量速率证据，除非模型确实计算。

CVD 等场景先固定沉积材料、反应体系和适用条件。相同前驱体加入不同共反应物可得到不同薄膜；不得把一种工艺的覆盖性结论直接移到另一种工艺。总反应方程不是单步表面机制；反应饱和、氢覆盖、中间体和局部输运可能改变速率律。

宏观传质受限与特征尺度沟槽耗尽相关但不是同一判据。若演示覆盖率，先定义顶部、侧壁、底部厚度和比较时刻；不同参数下比较相同时间与相同顶部厚度会回答不同问题。精确预测封口/空洞需要适用的生长几何和输运模型；教学构造须明确标成趋势示意，不以光滑动画掩盖无依据的数值。
