# 视觉与交互规范

## 主题与含义分离

使用语义化令牌管理 background/surface/text/muted/border/control/selection/category/quantity-scale。选择色、警告色、对象类别色不能不加区分共用一个 accent。换肤允许更换具体色值，但保持角色差异、顺序/发散含义和必要对比。色彩只是辅助编码，不承担全部含义。

暖浅底是本用户的偏好，不是科学可视化的普遍定律。禁止把“低蓝光”“护眼”外观偏好宣传成医疗效果。避免高饱和整片填色；需要表达连续数值时使用恰当色阶，不强制全图低饱和导致差异不可见。

## 形状、表面与版式

- 统一少量圆角档位，按控件、浮层、图框角色分配；不要每个段落都有卡片，不为统一圆角裁切科学图形。
- 毛玻璃仅在需要前后层次且不遮挡关键图形时采用；验证动态背景上的文字对比和性能，提供不透明回退。它是可选样式，不是质量指标。
- 留白建立分组；边框和阴影用于边界或层级，不装饰每个元素。
- 字体、字号、行距优先保障移动端阅读；图标签按实际显示尺寸排版，不随整张SVG缩小到不可读。
- 先看到主对象、主要操作和反馈。必要基础用近旁短说明；长推导按需展开，关键含义不可仅藏在展开层。

## 操作语法

| 意图 | 行为边界 |
|---|---|
| 改变系统 | 仅改变允许的自由输入，联动派生量，显示约束 |
| 观察结构 | 旋转/平移/缩放/剖切只改观察状态 |
| 读取局部 | 选中/探针只读状态，必要时固定读数以比较 |
| 推进过程 | 区分物理时间、算法步骤与教学构造，可暂停和恢复 |
| 比较状态 | 明确哪些量固定、哪些改变；需要同时比较时不藏在互斥页签 |

一个动作一种可预测的含义，不依赖隐藏模式。同一变量只维护一个状态源；第二入口必须有不同使用价值，不能仅因喜欢按钮再放一个同义下拉框。

触摸直接操作优先，但不得让必要功能只能拖动或双指完成。提供等价点击/数值入口，键盘支持不能单独替代触屏点击。替代入口可以按需显示，但应可发现。不要为“简洁”隐藏所有入口，也不要为“可访问”堆满重复控件。

手势命中区不能互相覆盖或劫持正常页面滚动。验证单指变双指、抬起一指、pointercancel、移出区域、后台返回。避免全页禁缩放。复位视角不重置模型，重置实验须说明范围。

## 动画约定

跟手更新不添加滞后缓动；程序切换用短过渡保持对象身份。项目可从约180–320ms的界面过渡起步，视对象距离和阅读需求调整；这不是统一生理阈值。教学构造可以更慢且可暂停。必要模型过程不为追求丝滑插值成无效状态。

不自动循环抢注意力；中断从当前状态继续或明确取消。减少动态偏好下保留等价静态/步进结果。性能看实际目标设备，不看文件大小或开发机帧率猜测。
