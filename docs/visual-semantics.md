# 视觉含义：一套交互、一份字典

## 先区分五件事

| 含义 | 要回答的问题 | 常用表示与边界 |
|---|---|---|
| 对象身份/组成 | 它是什么，还是不是刚才那个对象？ | 稳定对象ID、底色、必要形状；化学反应中保持元素身份，分子身份可随反应改变 |
| 物理状态/连续量 | 它现在处于什么状态，数值是多少？ | 几何、数量、连接、数值或声明了尺度的色图；与身份着色分开 |
| 关系/异常 | 相对于什么，哪里缺失、错位或不满足约束？ | 正常基准与实际结构的可见差别；不要把关系异常涂成“坏原子” |
| 关注范围 | 当前让读者看哪里？ | 必要时用细描边、短暂强调或局部聚焦；不自动加光圈，不改变组成色 |
| 观察工具 | 哪些只是帮助看的东西？ | 镜头、探针、切片、虚影；区分真实结构与辅助标记 |

不把“底色只能表示元素”推广成所有学科规则。温度场、概率密度、组织分类可以用色，须声明角色、尺度和模式。若同一球既要表达种类又要表达温度，选择独立通道或显式全局表示模式，不能悄悄复用底色。

## 范围与跨状态一致性

一份语义范围默认覆盖同一作品所有模式、页签和尺度。为每个 `scope + channel + token` 只登记一个 `role + meaning`。主题可更换 token 的色值，不可变更 meaning。颜色相同而意义不同的冲突，不能靠给每页都贴图例解决。

同种原子在正常与缺陷状态、晶界两侧、反应前后保持元素编码。不同晶粒不因此是不同元素；另一相也未必改变元素组成。需要区分晶粒/相，用真实取向、排列和形态，或明确切到全局取向/相模式。原子着色与场的颜色可分开，但对象及范围要明示。

宏观颗粒若代表分子群、浓度采样或示踪标记，不与微观单个原子使用完全相同的图形而只靠文字说明。换尺度明确标出“局部放大/截面/示意”，保持可追踪的区域对应，不假装整体质量对应单个示踪点。

## 标记要与结构贴合

每个辅助标记登记所指对象ID与点/线/区域范围。位错线的强调不能填满半张原子面；辅助线不应像插入的实体棍子。需要连线时从真实对象坐标投影，遵守透视、遮挡和旋转。确需穿透显示时明确这是透视观察方式。

选用结构本身的缺失、错位、弯曲、取向、密度变化表达异常。若原图看不出结构，仅靠高亮告知答案，先修结构与视角，再加强调。

透明度仅表达已声明的深度/观察淡化或有尺度的量。被淡化的原子仍然存在，不能同时拿透明度表示物质消失。空位符号不是空心原子，观察切片不是物理界面，虚影不是额外物质。

## 最少而足够，不盲目加码

删除一个标记，若不损失识别、操作或理解就删。颜色已经与位置、动作及近旁短图例一起足以辨认时，不在每个球重复 A/B。可访问性需要针对任务检查：用少量图例、必要形状差异或结构化文字替代，而非默认密集字母。堆垛 A/B/C 表达层的位置序列，有独立教学价值；不能因为反位图 A/B 冗余而一概禁止。

同样，去掉多余颜色不能让关键对象重新淹没。强调的强度服务当前任务，避免红色大面、粗边与多个高亮竞争。

## 四个强制问题

对初始态、基准态、目标态、过渡态、换页后各问：
1. 每个显著颜色/形状现在是什么意思？与刚才是否一致？
2. 图上看起来变化的东西，模型里是否真的变化？没动的同色对象是否合理？
3. 读者是否能看见基准和差别，而不只是“这里有问题”的标记？
4. 遮住长解释，只留必要短标签，会不会把工具当实体、把同类原子当另一物质？

任一冲突先修图形或状态，不追加解释让学习者记忆例外。
