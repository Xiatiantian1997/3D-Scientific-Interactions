# 触摸与操作区

## 默认交互

- 图内空白短按：恢复本图声明的基准。三维默认只恢复朝向与缩放；动态实验恢复声明的初始状态。不得顺带清除无关参数或主题。
- 对象拖动：操纵对象或观察工具；三维旋转方向与手指一致。双指用于缩放。
- 短按必须位移不超过 8 CSS px、时长小于 500 ms。多指、pointercancel、失去捕获或页面滚动不得在松手时触发复位。
- 图边保留一句轻提示。默认入口不能完全隐藏。键盘替代入口与常用控制处于同一操作区，可放在折叠精细调节内。
- 空白已有放置、取样等功能时，不覆盖原功能；在图内或紧邻图的同一区域提供明确的复位目标。

## 集中布局

一个连续的图形区域，紧接一个紧凑操作区。播放、进度、比较和模式均在该区；不得把控制分散在图上方、下方和远处。局部放大可以作为同一图的关联视图，不另设一套控制。

## 三维接缝

球、杆和表面使用统一三维坐标与尺度。连接端点、半径和遮挡按真实几何表面处理，不把整根线按单一平均深度排序。球与杆采用一致光照，避免描边形成假裂缝；教学虚影是独立的观察参考，不能覆盖实体造成假穿模。旋转、缩放、复位全过程保持身份和几何不变。

## 本次验证与边界

硅局部配位改用球及圆柱胶囊距离场逐像素遮挡。EGL/GLES 编译与三个角度渲染完成，其中斜侧与重叠图经过目视检查。交互事件使用模拟 DOM 检查；真实手机宿主和多指手感尚未实测。本约定已用于扩散与硅配位，本次没有批量改写其他旧例子。


## 布局稳定性（本次修订）

- 状态变化不能改变控制项的占位。播放/暂停使用等长标签及固定的外部布局列，动态读数使用等宽数字和预留宽度。
- 展开内容不得作为按钮行的 flex 子项参与重排。展开入口独立成行，内容向下展开，不挤动其他按钮。
- 已有明确图内复位入口，不再额外添加可见复位按钮。需要键盘替代时使用可发现的键盘快捷操作，不重复占位。
- 本次晶胞和扩散保留图内空白复位，键盘焦点在交互内时 R 复位。根区域关闭滚动锚定以减少内部内容变化引起的跳动；宿主外层滚动仍需设备检查。
- 验证记录：两份源码的JS语法、HTML闭合、展开内容不在控制行、重复复位按钮移除均已检查；未声称已通过真实手机布局测试。
