# 3D 实验室 · SOP

## 1. 明确教学目标与模型

1. 写明要观察的对象、关系或变化，以及读者完成操作后应理解的内容。
2. 声明对象身份、几何关系、参数范围、默认值、单位、数据依据与适用条件。区分真实数据、理想化模型和纯展示构造。
3. 将输入参数、派生数值、观察参数和时间分开。旋转、缩放、展开、剖切与外观切换只改变观察，不改写科学数据。
4. 给可选择对象分配稳定标识；图形、控件、读数和说明共用同一份状态。
5. 需要对照时，先定义基准与比较对象，再确定共用的视角、尺度、色标和探测位置。

## 2. 分配职责并接入 2D 共用能力

按照 2D 规范接入控件、触摸、局部复位、播放和基础排版，不另建一套三维操作语义。

| 层级 | 负责内容 |
| --- | --- |
| 模型 | 结构、科学含义、数据、约束与默认值 |
| 交互 | 选择、参数调整、观察、播放、取消与复位作用域 |
| 基础 UI | 控件呈现、命中范围、文字、布局与反馈 |
| 主题 | 页面装饰、控件外观及允许配置的视觉样式 |

三维模型、相机和整体／局部展示位置按对象设计。上层 UI 可以调整尺寸、排列和装饰；不能改变科学含义、参数约束或复位范围。更换控件行为时显式适配事件、跟手方向与可访问操作。

## 3. 建立几何与观察方式

1. 先保证比例关系、结构层次、厚度、接缝、孔洞和遮挡正确，再添加材质。
2. 采用清楚的结构、柔和明暗和干净轮廓；按教学目标简化细节，避免无助于理解的装饰。
3. 默认视角展示关键结构。允许自由旋转与连续缩放，避免只能看见底面；转到侧面和背面仍应正确显示材质、截面与数据。
4. 相机和裁剪范围覆盖全部有效状态，避免操作中裁掉主要对象。
5. 仅在整体缩放仍无法看清关键细节时提供局部详图；详图与整体共享对象身份、科学参数与探测位置。

## 4. 选择结构展示方式

| 对象情况 | 采用方式 | 执行要求 |
| --- | --- | --- |
| 具有独立可拆部件的装配 | 爆炸 | 用位移显露装配关系；不把展示位移当作运行轨迹或维修拆卸顺序 |
| 连续整体或连续分层结构 | 剖切 | 封闭实体切面，保留厚度、孔洞和层间关系；详图保留相同剖切状态 |

按对象选用一种主要方式，不强行提供爆炸／剖切切换。两类都支持选中与三档外观。

展开程度或切入深度用一个连续滑条控制，声明范围、方向和默认值。它们属于观察参数，默认静止，不添加重复的展开、合拢或重播入口。

## 5. 设置材质与三档外观

先对照真实对象，再选择渲染类别。材质研究使用相同几何、视角、灯光和背景；样本包含平面、曲面与转角，只改变待研究参数。

| 渲染类别 | 应呈现的特征 |
| --- | --- |
| 哑光金属 | 银灰底色、宽而柔和的反射，转动时明暗自然变化 |
| 亮面金属 | 清楚而受控的亮暗反射，随视角变化，保留暗部与曲面结构 |
| 均匀非金属 | 均匀底色、柔和体积明暗、较弱反光 |
| 光滑非金属 | 保留底色，叠加柔和表面高光 |
| 透明 | 后方结构可见，边缘和表面可辨，叠层遮挡稳定 |
| 半透明 | 能透光，后方细节模糊，保留厚度感 |

同材料、同表面处理保持同一外观，优先靠几何、接缝、遮挡与明暗区分部件。金属默认银灰，铜、金等按本色处理；涂层按实际外观另设预设。按具体材料的颜色、透明性和表面处理选类，不按材料名称机械归类。

纹理默认关闭；实际表面确有颗粒、孔隙或加工纹且有教学作用时才添加。粗糙颗粒以表面尺度和起伏表达，不以随机黑白斑纹代替。轻量反射和 MatCap 用于观察表达，不作为真实光学计算。

每个三维展示，包括结构件，提供一个三档滑轮按钮：

| 按钮状态 | 显示方式 |
| --- | --- |
| 外观 · 正常 | 保留材质、面填充与正常遮挡 |
| 外观 · 勾线 | 在正常外观上叠加结构轮廓 |
| 外观 · 透视线稿 | 隐藏面填充，显示前后结构轮廓 |

三档按表格顺序循环。中央点击下一档，横拖选择；不另设重复勾线或透明控制器。切换保留选择、相机、缩放、结构进度与科学数据。

只画轮廓、折边、孔口和剖切边，不把三角网格当作结构线。数学曲面的辅助线须说明坐标含义。透视线稿是观察方式，不等于玻璃材质；保留读数和量纲，隐藏不再对应画面的色彩图例时保留布局空间。

## 6. 组织选中、整体与局部

1. 明确选择单位：部件、原子、分子、探针或其他教学对象。通过对象自身的可辨变化表达选中，不使用大包围框遮挡展示。
2. 有多个可选对象时保留部位滑轮按钮，与图内点选共用选中标识，提供被遮挡部位的选择入口。
3. 结构展示使用“让位＋前置展示”：整体保留所选对象原位，详图显示同一对象的观察副本，不把副本误算成额外部件。
4. 在正常与勾线档，选中时整体各部件保留本色并半透明；所选部件颜色稍实但仍可透视。详图保留材质和自身遮挡。
5. 在透视线稿档，整体与详图均隐藏填充，保持原位与所选对象的对应。
6. 选中后旋转、缩放只作用于详图，整体参照与展示背景保持不动。连续换选中断正在执行的过渡，避免动画堆积。
7. 同步展示对象名称、用途或科学含义，以及与本实验有关的数值。说明可放在侧面或下方，由上层 UI 安排。
8. 整体与局部都要清楚可见，按对象比例和屏幕空间采用左右、上下或其他布局，不固定为一种排列。

## 7. 配置控件与默认排版

| 操作 | 控件 |
| --- | --- |
| 一次性动作 | 普通按钮 |
| 两态切换 | 同一个普通按钮点击切换 |
| 部位、类别与离散档位 | 滑轮按钮 |
| 展开、剖切、缩放等连续量 | 连续滑条 |
| 真实时间过程 | 按 2D 时间条规则接入 |

只保留一个面板控制入口控制同一状态。图内操作与控件同步，不能各自保存不同数值。类别可首尾循环；有物理边界的数值不循环。滑轮的连续型能力、吸附和播放扩展按 2D 规范接入，不用带档位的普通滑条选择部位。

应用以下可由上层 UI 覆盖的默认排版：

1. 主图在上、操作集中在下；控件组与按钮居中。普通按钮尺寸统一，滑轮按钮可稍大，不默认撑满整行。
2. 按钮与按钮并列，滑条与滑条并列，同排文字基线与标题行对齐；窄屏按同类分组换行。
3. 短按钮文案放入按钮内，例如“部位 · 外壳”“外观 · 正常”，去掉外侧重复标题。滑条保留名称、读数与必要单位。
4. 相关控件相邻，顺序与所控制过程一致；滑条两端文案与数值方向一致。外观档位不排列成结构进度的步骤。
5. 切换状态、文案、图例和说明时保持布局稳定，避免主图和操作区跳位。尺寸与占位由 UI 层处理，不写入模型。
6. 只呈现本场景有明确作用的操作，不放置因逻辑冲突而突然无法点击的入口。折叠等共用行为按 2D 规范处理。

## 8. 实现手势、局部复位与时间

可见字带和刻度随手指同向移动；填充与数值指示按向右增长的映射处理。旋转按屏幕实际运动验收。拖动结束不追加点击；多指缩放与宿主滚动明确分工。

短按本区域空白执行局部复位并短暂反馈，不增加恢复、归位或重置按钮。

| 区域 | 复位动作 | 保留状态 |
| --- | --- | --- |
| 连续参数区 | 恢复该参数默认值 | 其他参数、选择、相机和基准 |
| 部位选择区 | 取消选择，返回整体 | 结构进度、相机和外观 |
| 图形观察区 | 有局部选择时退出局部；整体状态下恢复默认相机与观察缩放 | 科学参数、结构进度、外观和基准 |
| 其他状态组 | 恢复该组声明的默认状态 | 组外全部状态 |

控件、标签、文字、拖动、滚动、取消、多指及失去捕获不能触发空白复位；从控件拖到空白松手也不复位。提供作用域内键盘操作，不劫持文本输入。

图内选择、探测、播放和空白复位划分命中区域，一次操作只执行一个动作。

真实时间过程默认暂停。播放到终点回到起点并暂停，保留其他状态；拖动时间条临时暂停，释放恢复此前播放状态；失焦或后台暂停，返回不补算隐藏时间。结构观察滑条不使用时间播放语义。

## 9. 检查科学表达

| 场景 | 必做检查 |
| --- | --- |
| 原子与化学键 | 元素颜色表示身份；单、双、三键可辨；离域、配位、氢键与金属成键分别说明；不同定义的键能不混合比较，不据此直接推导运动或断裂速度 |
| 化学反应 | 对象身份可追踪；逐状态核对元素数量与电荷收支，开放体系说明流入流出；区分端点、阶段与真实时间，不把插值当反应机理 |
| 晶体与缺陷 | 按晶格、堆垛或实体关系选择表达，不默认添加棍棒；基准与缺陷共用视角和尺度，区分晶胞辅助边界与真实缺陷 |
| 数值颜色与体数据 | 标明量名、单位、有效范围、数据依据和色标；旋转与放大保持同一物理位置的数据，剖面与体数据同源 |
| 曲面与截线 | 标明坐标、量纲和截线位置；三维曲面、二维截线及读数共用模型；梯度或方向向量只在教学目标需要时加入，并说明所在空间 |
| 向量与路径 | 说明箭头方向、长度映射与采样位置；零向量可辨；区分几何路径位置、速度与时间 |
| 比较与联动 | 保持对象对应、基准、尺度与固定条件；仅改变声明的比较变量 |

数值缺失、超范围或模型无效时明确显示状态，不作为零值处理。对数映射由模型声明，滑条位置、刻度和读数一致。

材料本色、元素符号、数值颜色、选中反馈与页面主题分别管理。数据色值不被高光或选中强调改写；主题不任意覆盖科学对象的材料含义。

## 10. 验收与交付

1. 检查模型边界、单位、守恒、对象身份与数据依据；确认画面和说明表达同一含义。
2. 逐项操作全部控件，检查档位可达、跟手方向、连续范围、单一状态来源和拖后不点击。
3. 检查局部复位隔离、基准保留、取消、多指、快速换选、播放终点与后台暂停。
4. 旋转检查正面、侧面、背面及极端角度；核对遮挡、透明叠层、剖面封口、三档外观与选中说明。
5. 在窄屏和目标宿主检查文字、触摸范围、滚动冲突、布局稳定，以及整体和局部能否同时辨认。
6. 多实例隔离状态；二维与三维联动通过声明接口完成，不互相改写未授权状态。
7. 修改源码后生成对应 HTML，并分别记录模型检查、自动化、实际浏览器、宿主嵌入和目标触摸设备的验证结果。未执行项如实标明，不把代码检查当作真机验收。
8. 需要审看时每次提供两个小样；确认后保存可复用源码、参数、使用说明与验收结果，不把试验过程写入执行 SOP。
