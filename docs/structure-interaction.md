# 结构交互：从 CVD 炉管提炼的方法

## 采用依据

2026-10-31，用户在查看 CVD 三维炉管后反馈“不错，感觉是可以的”，并要求总结、写入项目。本例可作为后续设备结构讲解的参考基线。这是对本例的认可，不代表所有交互、物理细节和设备性能已经验证。

参考作品：[CVD 三维结构](../examples/cvd-structure-3d.html)。
模型边界与来源：[结构说明](cvd-structure.md)。

## 核心方法

**先让结构本身解释关系，再用操作逐层揭示；文字负责命名与补充，不替看不懂的图辩解。**

1. **先选一个能讲清的对象。** 本次只做一台水平热壁炉管，不把不同 CVD 类型和整座工厂强塞进一个场景。优先选择能解释内外、连接、支撑或运动关系的局部系统。
2. **先搭装配关系，再加外观。** 炉壳包围加热层，石英管容纳晶舟，晶舟支撑晶圆，端盖连接接口。三维坐标、部件层级与连接位置先正确，再加圆角、材质与细节。
3. **从整体进入内部。** 完整结构建立整体印象；展开让被遮挡的部件显露；合拢帮助读者把局部放回整体。拆解顺序服务理解，并明确是否为教学剖开。
4. **一个装配体整体运动。** 晶舟与其晶圆、端盖与其螺栓保持稳定对应和相对位置。不能为了转场方便，让同一装配体一部分平移、一部分淡出。
5. **每个操作立刻有可见后果。** 展开进度直接改变部件位置；选部件应让它处于可见状态并解释作用；旋转只改视角；复位视角不清空展开状态。避免同一变量重复放按钮和下拉框。
6. **细节有用途，色彩有固定含义。** 保留能帮助识别的圆片、法兰、端口、支撑和密封关系。颜色表示部件身份，不随选择突然变成温度、缺陷或另一种物质；强调另用轻微明暗或轮廓。柔和暖底与少量蓝灰色适合本用户，但不是通用配色定律。
7. **美观支持辨认。** 用厚度、阴影和遮挡表达实体，不靠强烈色块、漂浮棍子或无关截面表达结构。装饰性螺丝、毛玻璃和三维效果都应服从解释价值。
8. **讲清观察和物理的边界。** 炉管剖开、部件展开是观察构造，不是设备运行或维修步骤。真实气流、反应、生长若加入，应独立建模，不能由拆解进度伪造。

## AI 的执行顺序

- 写一句读者应理解的关系，并列出最容易误会的地方。
- 查实际结构和适用工艺，写出部件、连接、层级、简化项。
- 明确对象身份、颜色含义、动作后果和固定条件。
- 先做“整体 → 揭示内部 → 回到整体”的最小闭环。
- 检查初态、展开、旋转、途中反向与重新选择，保留对象对应。
- 在小屏检查关键部件大小和控制区域；单指、双指与页面滚动的冲突需要实际验证。
- 将用户认可的能力写入保留清单；后续改版先做回归，不因统一样式把它们删掉。

参考 Anatomy 的表达思想，不等于必须使用其渲染器、复杂度或所有装饰。工具选择由交付环境、触屏性能和理解目标决定。

## 什么时候使用，什么时候不用

适合：层层包围的设备、内部遮挡明显的结构、装配与连接关系、整体和局部容易失去对应的对象。

不自动适合：读精确数据、比较微小差异、理解概率或公式依赖。此时二维曲线、同位置切换、基准虚影可能更有效。需要正常/缺陷或参数前后比较时，仍须保留基准，不能用“能旋转”替代比较。

本次三维图关注结构；微观化学、特征尺度覆盖和宏观气路可作为同一讲义的独立层次，不要求全塞进同一画面。

## 后续必须保留

- 连贯的实体结构，以及部件整体运动。
- 展开、合拢、旋转与视角复位各有明确作用。
- 点选部件后能看见对象，说明与画面对应。
- 手机可读、轻量、无需先下载才能查看。
- 不伪装成工程 CAD、分子动力学或经过校准的工艺仿真。
